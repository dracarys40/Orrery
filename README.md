# Orrery
An interactive 3D Solar System Explorer featuring realistic planetary motion, detailed planet visualizations, orbital trails, zoom controls, and NASA/JPL-inspired information. Explore the planets, inspect celestial bodies, control time, and experience our solar system through an immersive, browser-based experience built with WebGL.

# The Solar System · Interactive Explorer

The Solar System Interactive Explorer is a project I built to explore our Solar System in an interactive 3D environment. It lets you explore planets, zoom in on them, view information about different celestial bodies, and watch the planets move along their orbits.

## Features

* Interactive 3D Solar System
* Detailed planet textures and visualizations
* Planet information inspector
* Zoom and camera controls
* Planetary motion and orbit trails
* Pause and play controls
* Today button to return to the current simulation date
* Session timer to track time spent in the app

## Built With

* HTML
* CSS
* JavaScript
* WebGL

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server, or open it directly in a compatible browser.
